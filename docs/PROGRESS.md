# Прогрес

## Зроблено (коміти до 2026-09-26)
- Структура проєкту WinUI 3
- Шар API EcoFlow: вхід у хмару, Developer API, MQTT
- Шар протоколів: інтерфейс і Delta 2 (JSON)
- UI: екрани входу, списку станцій, деталей, налаштувань
- Фоновий моніторинг і сповіщення

## 2026-09-27: код-рев'ю та виправлення
Проєкт збирається (`dotnet build -p:Platform=x64`: 0 помилок; лишилося тільки попередження NETSDK1206 від Windows App SDK 1.5).
Логіку звірено з Android-версією (PowerHub).

### Виправлено
- [x] **Формат MQTT:** `JsonMessages.Parse` читає `params` (телеметрія) та `data.quotaMap` (відповідь `latestQuotas`), а раніше розгортав увесь конверт повідомлення і ключі не збігалися. Protobuf-кадри відсіюються
- [x] **MqttLink:** підписка на всі топіки (раніше лише на останній), відписка від усіх, власний цикл перепідключення кожні 5 с, помилки автентифікації передаються в `onFatal`, синхронний `Dispose` з таймаутом. ClientId у форматі `ANDROID_…`, як в офіційному застосунку
- [x] **MonitorService переписано:** повторний вхід і нові облікові дані MQTT при кожному підключенні з наростаючою затримкою (від 5 с до 5 хв); підписка на `get_reply` і `set_reply`; запит `latestQuotas` після підключення і раз на 5 хв; незмінні знімки параметрів під lock; станція офлайн, якщо даних немає понад 3 хв; історія раз на хвилину; очищення історії раз на добу; оновлення станцій і сповіщення тільки в UI-потоці через DispatcherQueue; статус з'єднання показується на головному екрані
- [x] **Сповіщення:** `NotificationService.Evaluate` за логікою Android (правило спрацьовує один раз, поки умова не зникне, з гістерезисом): живлення зникло/з'явилося, низький заряд, повний заряд, офлайн
- [x] **Список станцій:** синхронізація через Developer API (під час старту моніторингу, кнопкою «Оновити», під час збереження ключів), додавання вручну за серійним номером; видалені користувачем станції синхронізація не повертає
- [x] **Вхід:** після входу моніторинг запускається; `IsLoggedIn` не залежить від 24-годинного токена; зберігається регіональний сервер (`ApiHost`)
- [x] **Потокобезпечність:** Repository з lock, `Device` реалізує INotifyPropertyChanged (телеметрія не зберігається на диск), окремий `HistoryDbContext` на кожну операцію, `ExecuteDeleteAsync` для очищення
- [x] **Безпека:** ключі Developer API перенесено в зашифроване сховище (зі старих налаштувань мігруються автоматично); DPAPI через `System.Security.Cryptography.ProtectedData` замість синхронного очікування асинхронного виклику; `*.pfx` додано в `.gitignore`
- [x] **UI:** тема застосовується одразу; усі перемикачі сповіщень зберігаються; сторінка деталей оновлюється в реальному часі (включно з сонячною потужністю й циклами); захист від `GoBack` без історії навігації
- [x] `DetectFromSerial` не падає на коротких номерах і враховує `productName`
- [x] `BatteryWatts` = вхід мінус вихід (було скопійовано з InputW)
- [x] Увімкнено `<Nullable>enable</Nullable>`
- [x] Тимчасові логотипи в `Assets/` для MSIX
